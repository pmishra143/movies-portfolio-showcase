# Source provenance and honest scope

This showcase was prepared from a private local project using a fresh repository. No private Git history was imported. Original project names, internal paths and private-file fingerprints are intentionally omitted from this public document; the owner's inspection record is retained privately.

## Adapted work

The public quality-ranking function adapts an existing audience/critic/vote-confidence formula. The public implementation uses fictional fields and values; it does not distribute provider data or claim that those values are live ratings.

Workflow understanding came from the owner's existing discovery, ingestion and cached-serving implementation. Those observations inform the private-app description, not a claim about live deployment state, uptime, data rights or external performance.

## Newly written public components

- Static navigation, title dialogs, browser-local watchlists, filtering, insights and original SVG artwork.
- Twenty-four fictional records and a deterministic generator.
- Validated atomic snapshot publication and browser-side contract checks.
- A separate loopback-only API example using a file-version/cache boundary; not the private production handlers.
- Tests, browser exercises, CI, operating documentation and the explicit local failure simulation.

## Exclusions and limits

Private data, preferences, photographs, credentials, provider exports, live AI connections, authentication, deployment configurations, private hostnames and unrelated applications are excluded. The public edition is a focused demonstration, not the complete private application or evidence of a production SLO.

This repository distributes newly authored code/assets and the owner's adapted ranking formula. Earlier public commits retain their original contents; this redaction reduces current-page disclosure and does not erase history.
