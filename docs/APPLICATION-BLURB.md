# Portfolio wording

**Short application field**

Independent project: built and operated a personal movie/series discovery app. A separate public showcase demonstrates searchable catalog browsing, filtering, transparent ranking, browser-local watchlists, schema validation and tested snapshot publication. The public edition uses original fictional data and is isolated from the private application.

Live demo: https://pmishra143.github.io/movies-portfolio-showcase/
Source: https://github.com/pmishra143/movies-portfolio-showcase

**Interview walkthrough**

Start with the product journey, then show the explicit snapshot date and a failed-refresh exercise. Explain how invalid publication input preserves a previous snapshot, demonstrate the test, and distinguish the new public implementation from the private application's actual ingestion and caching code. Discuss tradeoffs and improvements without inventing production metrics or claiming affiliation with a prospective employer.
